Hackathon project by Alex & Thomas for the Tacto Negotiation Arena. Challenge instructions: [`CHALLENGE.md`](CHALLENGE.md).

## The idea

See [`docs/IDEA.md`](docs/IDEA.md).

## Getting started

```bash
git clone <repo-url>
cd alex-thomas
cd starter-kit
cp .env.example .env
uv sync --all-extras
uv run arena me
```
